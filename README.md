# Finite

A full-stack Instagram-inspired social media application built to practice modern web development, authentication, API integration, and frontend–backend communication.

## Features

- User registration and authentication
- Responsive Instagram-like UI
- Smooth navigation and clean layout
- Post feed and social profile interface
- Built for a polished frontend experience

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Node.js
- Express
- MongoDB

## Purpose

This project was built primarily as a learning project to strengthen my understanding of full-stack development and how the frontend, backend, database, and authentication work together in a real application

## What I Learned
- Building a full-stack application from scratch
- Connecting a React frontend with an Express backend
- Designing and consuming REST APIs
- Handling user authentication
- Working with MongoDB and database model
- Managing frontend state and API responses
- Structuring frontend and backend code
- Handling errors and debugging API requests
